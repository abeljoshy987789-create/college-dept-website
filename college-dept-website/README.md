# College Department Website (HTML)

A simple multi-section website for the Department of Computer Science, built with HTML5 and a little CSS.

**Covers:** document structure, headings/paragraphs, lists, hyperlinks, images, tables, forms and semantic elements.

## Run
Open `index.html` in any web browser.

## Structure
- `index.html` - page content
- `style.css` - styling
- `images/logo.svg` - department logo
- `screenshots/` - screenshots used in the report
